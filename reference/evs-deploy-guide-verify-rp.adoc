= Vérifiez que tout fonctionne dans NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Après avoir ajouté un plan de réplication dans NetApp Disaster Recovery, vérifiez que le plan est dans l’état *Healthy* avant de continuer.

Figure : Page des plans de réplicationimage:evs-replication-plan-post-create.png["Page des plans de réplication"]

NetApp Disaster Recovery exécute une série de tests pour vérifier que tous les composants, y compris le cluster ONTAP, les clusters vCenter et les machines virtuelles, sont accessibles et prêts à être protégés. Ce contrôle de conformité est effectué régulièrement.

La page des plans de réplication affiche les informations suivantes :

* Statut du dernier contrôle de conformité
* L'état de réplication du plan de réplication
* Le nom du site protégé (source)
* La liste des groupes de ressources protégés par le plan de réplication
* Le nom du site de basculement (destination)
