= Accéder à la NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
Pour vous connecter à NetApp Disaster Recovery, utilisez vos identifiants du site de support NetApp ou inscrivez-vous pour obtenir un identifiant cloud NetApp avec votre adresse e-mail et votre mot de passe https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["En savoir plus sur la connexion"^].



[[user-roles]]
== Rôles des utilisateurs

Dans Disaster Recovery, certaines tâches nécessitent des rôles utilisateur spécifiques. Assurez-vous d'avoir attribué aux utilisateurs les rôles corrects.

Pour plus d'informations, voir : * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["rôles et autorisations des utilisateurs dans NetApp Disaster Recovery"] * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["NetApp Console rôles d'accès pour tous les services"^]



[[log-into-disaster-recovery]]
== Connectez-vous à Disaster Recovery

. Ouvrez un navigateur web. Accédez à  https://console.netapp.com/["NetApp Console"^].
. Connectez-vous à la NetApp Console.
. Dans la navigation de gauche de la NetApp Console , sélectionnez *Protection* > *Reprise après sinistre*.
+
Si c'est la première fois que vous vous connectez à ce service, la page de destination apparaît et vous pouvez vous inscrire pour un essai gratuit.

+
image:draas-landing6-free-trial.png["Capture d'écran de la page d'accueil pour la reprise après incident"]

+
Sinon, le tableau de bord de reprise après incident s'affiche.

+
** Si vous n'avez pas encore ajouté un agent NetApp Console, ajoutez-en un. Pour plus de détails, consultez https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["En savoir plus sur les agents de console"^].
** Si vous êtes un utilisateur de la console disposant d'un agent existant, lorsque vous sélectionnez *Disaster recovery*, un message vous invitant à vous inscrire apparaît.
** Si vous utilisez déjà le service, lorsque vous sélectionnez « Récupération après sinistre », le tableau de bord apparaît.
+
image:dr-dashboard.png["Tableau de bord de reprise après incident"]
